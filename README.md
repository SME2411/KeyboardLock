# Keyboard Lock — бета 0.1.0

Небольшая утилита для Windows: временно блокирует ввод с клавиатуры, оставляя мышь и тачпад доступными. Приложение работает из области уведомлений и не требует установки.

## Скачать и запустить

Скачайте [KeyboardLock.exe](./KeyboardLock.exe) и запустите его. Значок появится рядом с часами Windows. Если значок не виден, нажмите стрелку вверх в области уведомлений.

- Щёлкните левой кнопкой по значку, чтобы включить или снять блокировку.
- Красный значок означает, что клавиатура заблокирована; зелёный — что ввод включён.
- Щёлкните правой кнопкой, чтобы открыть меню.
- Сочетание **Ctrl+Alt+F12** переключает блокировку.

Программа не требует установки. Чтобы закрыть её, откройте меню значка и выберите выход. Некоторые системные сочетания Windows, например **Ctrl+Alt+Delete**, остаются под управлением Windows.

# Keyboard Lock — beta 0.1.0

A small Windows utility that temporarily blocks keyboard input while leaving the mouse and touchpad available. It runs from the Windows notification area and does not require installation.

## Download and run

Download [KeyboardLock.exe](./KeyboardLock.exe) and run it. Its icon appears near the Windows clock. If it is hidden, open the notification-area overflow menu.

- Left-click the icon to toggle the keyboard lock.
- Red means locked; green means keyboard input is enabled.
- Right-click the icon to open the menu.
- **Ctrl+Alt+F12** also toggles the lock.

To exit, open the icon menu and choose Exit. Some Windows system shortcuts, such as **Ctrl+Alt+Delete**, remain controlled by Windows.
