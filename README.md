# Keyboard Lock

**A small Windows utility to temporarily block keyboard input while leaving the mouse and touchpad available.**

**Beta version:** 0.2.0 · **Languages:** English and Russian

## Download and use

Download [KeyboardLock.exe](./KeyboardLock.exe) and run it. No installation is required. The icon appears in the Windows notification area near the clock.

- Left-click the tray icon to toggle the keyboard lock.
- Red means locked; green means keyboard input is active.
- Right-click the icon to open the menu.
- Press **Ctrl+Alt+F12** to toggle the lock.
- Use **Exit** in the tray menu to close the app.

The interface uses Russian when the Windows UI language is Russian, and English otherwise. Windows system shortcuts such as **Ctrl+Alt+Delete** remain controlled by Windows. There is no automatic unlock timer yet.

# Русский

**Небольшая утилита для Windows, которая временно блокирует клавиатуру, оставляя мышь и тачпад доступными.**

**Бета-версия:** 0.2.0 · **Языки:** английский и русский

## Скачать и запустить

Скачайте [KeyboardLock.exe](./KeyboardLock.exe) и запустите его. Установка не требуется. Значок появится в области уведомлений Windows рядом с часами.

- Щёлкните левой кнопкой по значку, чтобы переключить блокировку.
- Красный значок означает, что клавиатура заблокирована; зелёный — что ввод включён.
- Щёлкните правой кнопкой, чтобы открыть меню.
- Нажмите **Ctrl+Alt+F12**, чтобы переключить блокировку.
- Выберите **«Выход»** в меню значка, чтобы закрыть программу.

Если язык интерфейса Windows — русский, меню программы будет на русском; для остальных языков — на английском. Системные сочетания Windows, например **Ctrl+Alt+Delete**, остаются под управлением Windows. Таймера автоматической разблокировки пока нет.
