# Развёртывание DuoVerse на VPS (Ubuntu 24.04)

Итог: чат на `https://твой-домен`, автозапуск, HTTPS, файрвол, ежедневный бэкап. Бюджет ≈ $5-6/мес + домен ≈ $10-12/год (цены сверь на сайтах).

## 1. Домен
Купи у регистратора, который принимает Visa (Namecheap, Porkbun, Cloudflare Registrar). Не бери `.ru`/`.рф`.
По DNS-проверке `duoverse.com` и `duoverse.app` заняты; `duoverse.net` и `duoverse.xyz` не нашлись в DNS, но это **не гарантия свободы** — проверь на сайте регистратора.

## 2. Сервер
1. Создай VPS: Ubuntu 24.04, самый маленький тариф (1-2 vCPU, 2 ГБ RAM — с запасом), локация Финляндия/Германия (ближе к России, ниже задержка).
2. Добавь свой SSH-ключ при создании (`ssh-keygen -t ed25519`, публичный ключ — файл `.pub`). Вход по паролю не используй.
3. Запиши IP-адрес сервера.

## 3. DNS
У регистратора добавь запись **A**: `@` → IP сервера (и по желанию `www`).
Если домен на Cloudflare — поставь «DNS only» (серое облако), без проксирования: Cloudflare в России иногда режут/замедляют, а так трафик идёт прямо на твой сервер. Это моё предположение по общей практике, не проверенный факт.
Проверка: `nslookup твой-домен` должен вернуть IP сервера (обновление DNS до часа).

## 4. Установка
```bash
ssh root@IP_СЕРВЕРА
curl -fsSL https://raw.githubusercontent.com/SME2411/KeyboardLock/claude/chat-app-lf4nji/chat/deploy/setup.sh -o setup.sh
bash setup.sh твой-домен
```
Если репозиторий приватный, `curl` и `git clone` не сработают без доступа — тогда скажи, настроим deploy-ключ или зальём код через `scp`.

В конце скрипт напечатает **код приглашения** (он же в `/etc/duoverse.env`). Сохрани его.
`MAX_USERS=2` — больше двух аккаунтов не создать.

## 5. Первый вход
1. Открой `https://твой-домен` → «Зарегистрироваться» → имя, пароль, код. Девушка делает то же.
2. После двух регистраций можно закрыть регистрацию совсем: в `/etc/duoverse.env` удали строку `INVITE_CODE=...` и выполни `systemctl restart duoverse`.
3. iPhone: открыть сайт в **Safari** → «Поделиться» → «На экран "Домой"», дальше входить внутри этого значка.

## 6. Обслуживание
| Что | Команда |
|---|---|
| Логи | `journalctl -u duoverse -f` |
| Перезапуск | `systemctl restart duoverse` |
| Обновить код | `bash /opt/duoverse/chat/deploy/update.sh` |
| Бэкапы | `/var/backups/duoverse/` (14 последних, ежедневно 04:00) |
| Автообновления безопасности | включены (`unattended-upgrades`) |

Бэкапы лежат на том же сервере — при потере сервера пропадут. Раз в месяц копируй их к себе: `scp root@IP:/var/backups/duoverse/chat-*.db .`

## Что скрипт делает
Ставит Node 22 и Caddy, создаёт пользователя `duoverse` без shell, кладёт код в `/opt/duoverse`, базу в `/var/lib/duoverse`, секреты в `/etc/duoverse.env` (права 600), запускает сервис с изоляцией systemd, включает файрвол (открыты только SSH, 80, 443).
Приложение слушает только `127.0.0.1`, наружу смотрит только Caddy.
