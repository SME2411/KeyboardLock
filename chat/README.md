# DuoVerse (private chat)

Маленький приватный чат на двоих (до `MAX_USERS`). Node.js + WebSocket + SQLite, веб-приложение (PWA).

## Запуск
```bash
npm install
INVITE_CODE=придумай-длинный-код npm start     # http://localhost:3000
```
Первый раз: «Зарегистрироваться» → имя, пароль (8+), код приглашения. Без `INVITE_CODE` регистрация закрыта.

## Переменные окружения
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | 3000 | порт |
| `INVITE_CODE` | пусто | код для регистрации |
| `MAX_USERS` | 5 | лимит аккаунтов |
| `COOKIE_SECURE` | 0 | поставь `1`, когда сервер за HTTPS |
| `DB_PATH` | `data/chat.db` | файл базы |

Нужен Node.js ≥ 22.13 (встроенный `node:sqlite`).

## Что есть / чего нет
- Есть: логин, личные сообщения в реальном времени, история, статус «онлайн», автопереподключение, установка на экран телефона, **Web Push** (уведомления при закрытом приложении, в т.ч. iPhone с iOS 16.4+ после установки на экран «Домой»), счётчик непрочитанных.
- Нет (пока): фото/голосовые, звонки, сквозное шифрование (сервер видит переписку; push-содержимое шифруется на пути к телефону).

## Push
VAPID-ключи создаются при первом запуске и хранятся в базе (попадают в бэкап). Переменная `VAPID_SUBJECT` (по умолчанию `https://duoverse-app.org`) — контакт для push-сервисов Apple/Google.
Сервер шлёт push, только если ни одно окно получателя не в фокусе (клиент сообщает об этом по WebSocket).
