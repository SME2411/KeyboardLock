# Private Chat

Маленький приватный чат на двоих (до `MAX_USERS`). Node.js + WebSocket + SQLite, веб-приложение (PWA).

## Запуск
```bash
npm install
INVITE_CODE=придумай-длинный-код npm start     # http://localhost:3000
```
Первый раз: «Зарегистрироваться» → имя, пароль (8+), код приглашения. Без `INVITE_CODE` регистрация закрыта.

## Переменные окружения
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | 3000 | порт |
| `INVITE_CODE` | пусто | код для регистрации |
| `MAX_USERS` | 5 | лимит аккаунтов |
| `COOKIE_SECURE` | 0 | поставь `1`, когда сервер за HTTPS |
| `DB_PATH` | `data/chat.db` | файл базы |

Нужен Node.js ≥ 22.13 (встроенный `node:sqlite`).

## Что есть / чего нет
- Есть: логин, личные сообщения в реальном времени, история, статус «онлайн», автопереподключение, установка на экран телефона, уведомления пока вкладка открыта.
- Нет (пока): push-уведомления при закрытом приложении, фото/голосовые, звонки, сквозное шифрование (сервер видит переписку).
