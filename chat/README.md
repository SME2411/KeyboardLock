# DuoVerse (private chat)

Маленький приватный чат на двоих (до `MAX_USERS`). Node.js + WebSocket + SQLite, веб-приложение (PWA).

## Запуск
```bash
npm install
INVITE_CODE=придумай-длинный-код npm start     # http://localhost:3000
```
Первый раз: «Зарегистрироваться» → имя, пароль (8+), код приглашения. Без `INVITE_CODE` регистрация закрыта.

## Переменные окружения
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | 3000 | порт |
| `INVITE_CODE` | пусто | код для регистрации |
| `MAX_USERS` | 5 | лимит аккаунтов |
| `COOKIE_SECURE` | 0 | поставь `1`, когда сервер за HTTPS |
| `DB_PATH` | `data/chat.db` | файл базы |
| `UPLOAD_DIR` | `<папка базы>/uploads` | куда складывать файлы |
| `MAX_FILE_MB` | 100 | максимальный размер файла |
| `MAX_STORAGE_GB` | 15 | потолок для всех файлов вместе |

Нужен Node.js ≥ 22.13 (встроенный `node:sqlite`).

## Что есть / чего нет
- Есть: логин, личные сообщения в реальном времени, история, статус «онлайн», автопереподключение, установка на экран телефона, **Web Push**, настройки на устройстве (тема по системе/светлая/тёмная, стили Графит/Сланец/Янтарь, размер текста, анимации), эмодзи-панель, крупные эмодзи, статус «в сети / был(а) в…», «печатает…» (уведомления при закрытом приложении, в т.ч. iPhone с iOS 16.4+ после установки на экран «Домой»), счётчик непрочитанных.
- **Стиль «Telegram+»:** «хвостики» у пузырей, время в строке, обои чата (узор, точки, сетка, 3 градиента, своё фото с затемнением и размытием). **12 тем** (светлая/тёмная у каждой), генерируются `python3 tools/gen-themes.py` (строка на тему). **Профиль:** отображаемое имя, «о себе», цвет профиля, аватарка (видны собеседнику сразу). Настройки внешнего вида хранятся на устройстве.
- **Статусы ✓ / ✓✓** (отправлено / прочитано), **черновики** (у каждого чата свой, видны в списке), **список устройств** с завершением сеансов (в т.ч. удалённым выходом и закрытием соединения), скругление сообщений, очистка локальных данных.
- **Кнопка «Назад»:** каждый шаг (чат на телефоне, настройки и вложенные окна, панель эмодзи, просмотр фото) — отдельная запись в истории, «Назад» закрывает их по одному; на списке чатов первое «Назад» показывает подсказку, второе подряд выходит (на телефоне и в установленном приложении). Клавиатура и панель эмодзи сменяют друг друга; отправка не отнимает и не вызывает клавиатуру.
- **Интерфейс как в Telegram:** список чатов с превью, временем и непрочитанными (хранятся на сервере), на широком экране список слева и чат справа. Чаты: собеседник, **«Избранное»** (чат с самим собой для заметок и файлов), служебный **«DuoVerse»** (приветствие и инструкция, только чтение).
- **Файлы** (до 100 МБ): фото, видео, аудио, документы; скрепка, перетаскивание, вставка из буфера; просмотр фото на весь экран; фото сжимаются на устройстве (и теряют EXIF/геопозицию). Хранятся в `UPLOAD_DIR` (по умолчанию рядом с базой, `uploads/`), доступны только участникам переписки. Лимиты: `MAX_FILE_MB` (100), `MAX_STORAGE_GB` (15).
- Нет (пока): голосовые, «кружочки», стикеры, звонки, сквозное шифрование (сервер видит переписку; push-содержимое шифруется на пути к телефону).

## Push
VAPID-ключи создаются при первом запуске и хранятся в базе (попадают в бэкап). Переменная `VAPID_SUBJECT` (по умолчанию `https://duoverse-app.org`) — контакт для push-сервисов Apple/Google.
Сервер шлёт push, только если ни одно окно получателя не в фокусе (клиент сообщает об этом по WebSocket).
